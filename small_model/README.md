# AstraCore Nova Tiny v0.1

A small, practical byte-level language-model experiment. This first runnable model uses a **4-layer GRU**, not the proposed Nova Field architecture. It is a baseline to make training, checkpoints, and generation work end-to-end before experimenting with new computation.

## Requirements
Python 3.10+ and PyTorch. Install: `pip install -r requirements.txt`.

## Data
Put plain UTF-8 text files in `data/`. The trainer concatenates files, creates a byte stream (0–255), and splits it contiguously into train and validation segments. Use data you have permission to use. Keep test data separate for final evaluation.

## Train
`python -m small_model.train --data data --steps 1000 --batch-size 16 --seq-len 128`

The starter defaults are intentionally tiny. Training quality depends on corpus size, hardware, and steps. This is not a pretrained model and will initially generate poor text.

## Generate
`python -m small_model.generate --checkpoint checkpoints/latest.pt --prompt "Hello" --max-new-bytes 200`

Generated bytes are decoded with UTF-8 replacement for incomplete sequences.

## Model
- UTF-8 byte vocabulary: 256
- Embedding: 64
- GRU: 4 layers, hidden size 128
- Linear next-byte prediction head
- Parameter count is printed by the model script

This baseline is for reproducible experiments, not a claim of intelligence or architectural novelty. The existing Nova Field Dynamics prototype remains separate.
